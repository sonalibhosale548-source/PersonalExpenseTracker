# Personal Expense Tracker

## About the Project
Personal Expense Tracker is a console-based Java application developed to manage daily expenses. It allows users to add expenses, view all records, search expenses by category, delete records, and calculate total spending.

## Features
- Add a new expense
- View all expenses
- Search expenses by category
- Delete an expense using its ID
- Calculate total expenses
- Validate user input

## Technologies Used
- Java
- Java Collections Framework
- ArrayList
- Scanner
- Exception Handling
- LocalDate
- Eclipse IDE

## Core Java Concepts
- Classes and Objects
- Encapsulation
- Constructors and Methods
- Loops and Conditional Statements
- Switch Statements
- Collections
- Exception Handling

## How to Run
1. Import the project into Eclipse IDE.
2. Open `Main.java`.
3. Right-click and select Run As → Java Application.
4. Use the console menu to manage expenses.

## Storage
The current version stores expenses in memory using ArrayList. Data is cleared when the application exits.
